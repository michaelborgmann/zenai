title = 'OpenAI Launches Image Generation API'
+++

OpenAI now offers its latest image generation model, [gpt-image-1](https://openai.com/index/image-generation-api/), through an official API, allowing developers to embed customizable image creation into their own apps and platforms. The model, already used in ChatGPT, has helped generate over 700 million images for 130 million users worldwide. OpenAI plans to expand access to more tools and interfaces soon.
