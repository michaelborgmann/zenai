title = 'EMA Validates AI Diagnosis Tool'

The [European Medicines Agency](https://www.ema.europa.eu/en/homepage) (EMA) has validated an AI-based diagnostic tool for the first time. The AIM-NASH system by [PathAI] (https://www.pathai.com)assists pathologists in analyzing liver biopsy scans to assess the severity of metabolic dysfunction-associated steatohepatitis (MASH). EMA's qualification confirms that insights gained with the tool can be used as scientifically valid data in future clinical applications.
