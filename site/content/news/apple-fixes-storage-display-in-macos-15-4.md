title = 'Apple Fixes Storage Display in macOS 15.4'
+++

Apple has resolved an issue in the macOS 15.4 beta where the storage usage of Apple Intelligence was not displayed. The AI system requires at least 7GB of SSD space, which can be problematic for lower-end Macs. Initially, some speculated that Apple was hiding the storage usage to discourage disabling the AI features, but it was later identified as a bug related to System Integrity Protection. With the latest beta, the storage display is now visible again.
