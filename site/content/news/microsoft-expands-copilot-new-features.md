title = 'Microsoft Expands Copilot with New Features'

Microsoft has added new features to its [Copilot AI](https://copilot.microsoft.com) assistant, including Shopping, Pages, and Deep Research. CEO Mustafa Suleyman highlighted Copilot's goal to be an "AI Companion for everyone." The update includes memory and personalization options, with users maintaining control over their data via a dashboard.
