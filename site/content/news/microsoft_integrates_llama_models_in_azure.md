title = 'Microsoft Integrates New Llama Models into Azure'
+++

Microsoft has integrated the [Llama 4 Scout and Maverick](https://ai.meta.com/blog/llama-4-multimodal-intelligence/) models into [Azure AI Foundry](https://ai.azure.com) and [Azure Databricks](https://www.databricks.com). These models come with customizable safety features, like data filtering, to protect developers from misuse. The company also announced new tools for AI agent development, including an open-source Semantic Kernel framework and a Red Teaming Agent to test for security risks.
