title = 'MD Ryzen: AI Security Vulnerabilities'

[AMDs Ryzen-AI](https://www.amd.com/en/products/processors/consumer/ryzen-ai.html) processors have significant security flaws in their software and drivers, with four vulnerabilities identified. The most critical issues involve the NPU (Neural Processing Unit) driver, where three integer overflows allow attackers to execute malicious code.

Additionally, developers using the Ryzen AI Software Development Kit may expose themselves to risks due to improperly set default permissions, enabling attackers to escalate privileges and run arbitrary code. AMD has released updated software packages to address these issues.
