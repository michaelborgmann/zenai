[xAI](https://x.ai) has added two new features to its chatbot [Grok](https://x.ai/grok): an enhanced search function called "DeeperSearch" and an image editor. The "DeeperSearch" function, which replaces the previous "DeepSearch," takes more time for queries but doesn't show significantly better results in initial tests.
