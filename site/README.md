# ZenAI site

This is the [official website](https://michaelborgmann.github.io/zenai) for the [ZenAI](https://michaelborgmann.github.io/zenai/) project, built with [Hugo](https://gohugo.io) and hosted on [GitHub Pages](https://pages.github.com).

## Website URL

➡️ [https://michaelborgmann.github.io/zenai](https://michaelborgmann.github.io/zenai)

## Adding Content

To create a new article in the `news` section:

```
hugo new content/news/article_filename.md
```

## Running Locally

Start a local development server with:

`hugo serve`
